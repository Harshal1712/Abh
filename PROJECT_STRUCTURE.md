# Project Structure

- `frontend/`: The React-based UI application.
- `backend/`: Node.js API server for business logic and data access.
- `python-ml-service/`: Python microservice for geospatial inference and ML models (CatBoost).
- `models/`: Storage for joblib/pkl model files.
- `Processing/`: Storage for processed terrain rasters (DEM, Slope, Aspect).
- `sentel/` & `sentinel/`: Storage for Sentinel-1 acquisitions.
