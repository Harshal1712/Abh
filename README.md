# Assam Multi-Hazard Disaster Prediction

This project provides a multimodal disaster intelligence system specifically tailored for Assam. It includes a frontend, backend, and Python ML service.

## Architecture
- **Frontend**: React application for visualizing and reviewing events.
- **Backend**: Node.js service for API handling and database interactions.
- **Python ML Service**: A Python-based AI service using CatBoost for predicting Flood and Landslide risks based on geospatial data.
- **MongoDB**: Used for storing RiskEvents and configurations.

## Features
- AI message explanation
- Alerts and continuous monitoring
- Events Lab for analysts
- Expert Review workflow
- Field reporting
