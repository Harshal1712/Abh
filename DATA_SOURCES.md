# Data Sources

- **Rainfall**: Open-Meteo API
- **DEM/Terrain**: Copernicus GLO-30 / ALOS
- **Sentinel-1**: ESA Sentinel-1 GRD SAR data
- **Historical Events**: Assam State Disaster Management Authority (ASDMA) and NRSC.
- **Road Network**: OpenStreetMap

Limitations: Some datasets might be limited to specific date ranges for historical analysis.
